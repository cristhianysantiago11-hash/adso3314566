Propiedades de Texto en CSS

text-indent | white-space | word-break | text-overflow | direction | text-shadow

Sangría en la primera línea

Este párrafo tiene una sangría de 2rem en la primera línea. Es útil para simular la indentación de los libros o documentos formales.
Este párrafo normal no tiene sangría, para comparar.

Espacio en blanco (white-space)

white-space: normal → los espacios múltiples se colapsan y el texto se ajusta.
white-space: pre → respeta los espacios y saltos de línea.
white-space: nowrap → el texto no se quiebra y puede desbordar horizontalmente (usa scroll si es necesario).

Corte de palabras (word-break)

word-break: normal → Palabralarguisimasextranormal no se corta y desborda.
word-break: break-all → Palabralarguisimasextranormal se corta en cualquier punto.

Desbordamiento con puntos suspensivos

Este texto es muy largo y se cortará con puntos suspensivos.
Este texto es muy largo y se cortará sin puntos (clip).

* Requiere white-space: nowrap y overflow: hidden

Dirección de izquierda a derecha / derecha a izquierda

Normal (ltr): Texto de izquierda a derecha.
direction: rtl → Texto de derecha a izquierda (útil para idiomas como árabe o hebreo).

Sombra de texto

text-shadow: 1px 1px 1px rgba(0,0,0,0.1) → sombra sutil.
