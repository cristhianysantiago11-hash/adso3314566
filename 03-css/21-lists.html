📋 21 - Listas en HTML

Listas ordenadas (<ol>), desordenadas (<ul>) y de definición (<dl>)

🔘 Lista desordenada (<ul>)

Por defecto, los elementos se muestran con viñeta de disco.

  • Python
  • Java
  • JavaScript
  • C#

Con anidación correcta (sublista dentro de un elemento <li>):

  • Python
    • Flask
    • Django
  • Java
  • JavaScript

Cambiando el tipo de viñeta:

  • Viñeta círculo (list-style-type: circle)
  • Segundo elemento
  • Viñeta cuadrada (list-style-type: square)
  • Segundo elemento

🔢 Lista ordenada (<ol>)

Por defecto, números decimales (1, 2, 3...).

  1. Jujutsu Kaisen
  2. Frieren
  3. Hell's Paradise
  4. Journey with a Witch

Con anidación y tipo de letra "a":

  1. Jujutsu Kaisen
    1. Itadori
    2. Gojo
    3. Toji
  2. Frieren
  3. Hell's Paradise

Otros tipos de numeración:

  1. Mayúsculas (A, B, C...)
  2. Segundo elemento
  1. Romanos minúsculas (i, ii, iii...)
  2. Segundo elemento
  1. Romanos mayúsculas con CSS (upper-roman)
  2. Segundo elemento
  1. Letras griegas (α, β, γ...)
  2. No todos los navegadores lo soportan

📖 Lista de definición (<dl>)

HTML
Lenguaje de marcado para estructurar contenido web.
CSS
Lenguaje de estilos para diseñar páginas web.
JavaScript
Lenguaje de programación para añadir interactividad.

Se compone de <dt> (término) y <dd> (definición o descripción).
