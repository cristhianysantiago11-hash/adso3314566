22 - Cursor

La propiedad cursor cambia el tipo de puntero del mouse.

Pointer

Se usa normalmente en botones y enlaces.

Pointer cursor: pointer;
Muestra una mano al pasar el mouse.
Pasa el mouse aquí

Crosshair

Muestra un cursor en forma de cruz.

Crosshair cursor: crosshair;
Muy usado en herramientas de precisión.
Cursor tipo cruz

Move

Indica que un elemento puede moverse.

Move cursor: move;
Cursor de movimiento.
Cursor move

Text

Se usa en campos de texto.

Text cursor: text;
Cursor para escribir texto.
Cursor text

Wait

Indica que el sistema está cargando.

Wait cursor: wait;
Cursor de espera.
Cursor wait

Not Allowed

Indica que una acción no está permitida.

Not Allowed cursor: not-allowed;
Cursor de prohibido.
Acción no permitida

Help

Indica ayuda o información.

Help cursor: help;
Cursor de ayuda.
Cursor help

Grab

Simula agarrar un elemento.

Grab cursor: grab;
Cursor tipo mano de agarre.
Cursor grab

Custom Cursor

También se puede usar una imagen personalizada como cursor.

Custom Cursor cursor: url(...), auto;
Este cursor usa una espada personalizada.
Pasa el mouse aquí
