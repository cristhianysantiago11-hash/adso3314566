🎯 Pseudo-clases en CSS

:hover | :focus | :active | :first-child | :last-child | :nth-child | :not | :link / :visited

🖱️ Interacción del usuario

:hover → al pasar el ratón

:active → mientras se hace clic

⌨️ Focus en inputs

:focus → cuando el campo recibe el foco (tab o clic)

📌 Posición entre hermanos

:first-child (primer elemento) y :last-child (último)

  • Primer hijo (fondo azul claro)
  • Segundo hijo (color azul por :nth-child(odd))
  • Tercer hijo (color azul también)
  • Último hijo (fondo amarillo)

:nth-child(even) → filas pares en tabla

🚫 Exclusión con :not()

Este párrafo normal (sin clase) → color gris itálico

Este párrafo tiene clase "especial" → fondo gris claro, sin cambios de color

Otro párrafo normal → también itálico gris

* La regla p:not(.especial) aplica estilo a todos los párrafos que NO tienen la clase "especial".

🔗 Enlaces visitados y no visitados

:link → enlace no visitado (azul). :visited → enlace ya visitado (morado).
